Contact Us

We value feedback from the community. Whether you found a bug in a calculator, want to request a new feature, or need to reach us for legal reasons, here is how you can get in touch.

General Support & Feedback

For questions about how the calculators work, feedback on the design, or suggestions for new tools:

Email: hello@onerepmaxcalculator.me

Please allow 24-48 hours for a response. We are a small team.

Report a Technical Error

We take mathematical accuracy very seriously. If a calculator is producing an incorrect result, please email us with the following details so we can fix it immediately:

  • The name of the calculator you were using (e.g., 1RM, Plate Loader, Wilks).
  • The exact numbers you inputted.
  • The result the tool gave you.
  • What you believe the correct result should be (and the source of that calculation).
  • Your device type and browser (e.g., iPhone 14, Safari).
